## 证据与决定

单栋空闲诊断 SELECT 35→22；idle16 每 Tick 635.552→427.552，20800命中，事务、DML、JSON不变。63项候选针对性测试通过（含11项新测试），1201 Tick等价、Pending=0、共享供给、工资历史及未知提交/整图恢复均有回归。

但 active32 命中为0、SQL/事务/JSON总数相同，耗时却降逾一半，暴露本组可比性限制。active16结算均值94.620→124.167、最大118.543→293.096。上述是观察事实；不能证明所有收益或回退由候选造成。GC/JIT/CPU频率/系统调度只是可能原因，尚无直接证据。

**稳定且可重复的性能收益：不确定。50ms尖峰：仍存在。停止条件：4（证据不足）和8（6次上限）。** 无复跑、无探针关闭校准、无第二套方案。保留原已验阶段代码；候选源码和测试只归档在 [补丁](task-p/create-candidate.patch)，默认不应用。
